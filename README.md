# 趋势判断工作台 V2

我是 **DeFi狙击手**。我做了一个在自己电脑上运行的看盘工具。搜一个标的，选好周期，就能在 K 线上看到缠论中枢、当前方向和对应的入场区间、止损、两档止盈。V2 可以把 1 小时、4 小时和日线放在一起看，还会记下当时给出的判断，往后走够 12 根 K 线再核对结果。

[开发者的 X 主页](https://x.com/bi_9527zx) · [Telegram 讨论社群](https://t.me/jujishou9527) · [下载 Windows / macOS 版](https://github.com/nhovongoc0-max/trend-workbench/releases/latest)

## V2 更新了什么

| 更新 | 打开工作台后能看到什么 |
| --- | --- |
| 实时行情 | 接入推送的加密现货会随成交更新当前 K 线。断线时会重连，必要时切到定时刷新。A 股可看盘中公开报价。美股和期货的更新速度取决于交易时段、行情源和订阅权限，界面会区分实时推送、报价轮询和延迟行情。 |
| 黄金、白银和原油 | 除加密货币、美股和 A 股外，可在「大宗商品」中查看黄金期货、白银期货和 WTI 原油期货，或直接搜索品种名称。 |
| 更早的 K 线 | 把主图往左拖，到历史边缘会继续加载更早的数据。可回看的日期取决于标的、周期和行情源。美股和 A 股的 4 小时图还可以按交易日历查到哪个时段缺了一根。 |
| 看盘界面 | K 线、成交量和 MACD 分区显示，「专注看盘」可以扩大主图。选择做多或做空方案后，直接在对应价位旁看入场区间、止损和两档止盈。右上角可切换薄荷白、TradingView 深色、暖纸铜、冰川蓝和紫晶夜五套主题。 |
| 多周期与突破 | 移动十字线，可同时查看 1 小时、4 小时、日线在同一时刻最近完成的 K 线。打开「突破均价线」，可跟踪从中枢突破起的成交量加权均价。BTC/USDT、ETH/USDT 有可核对的同源数据时，还会显示突破后几分钟主动买卖各占多少。 |
| 方向成绩单 | 保存看盘或自选监测时实际出现的方向判断。第 12 根完整 K 线结束后核对方向，对照沿用此前走势的结果，并列出样本数。如果止盈和止损落在同一根 K 线，可用同源分钟行情核对先后。两者落在同一分钟时标为先后不明。 |
| 多空之战 | 打开币价旁的「多空之战」，看所选现货市场最近 60 秒的主动成交额。左侧绿军代表主动买入，右侧红军代表主动卖出，顶部显示价格。单笔达到 1 万 USDT 触发手榴弹，5 万触发炮击，25 万触发重炮，100 万触发空袭。爆炸处显示成交金额，也可调节音量和配乐。 |

**多空之战覆盖范围。** 行情源能提供逐笔成交的 USDT 现货交易对可以开启实时交战。画面里的买卖占比按单一现货市场的成交金额计算。其他报价币、永续合约和仅在链上成交的币种暂未接入战场。

## 打开后怎么看

以 BTC/USDT 为例。切到日线，如果看到 **日线偏空 · 周线偏多**，意思是日线结构在走弱，放到周线上看，结构仍然偏强。图上的入场区间、止损和两档止盈都按你选中的日线计算。切到 1 小时，就重新按小时线计算。这个例子用来解释界面，实际方向会随行情变化。

| 想看什么 | 工作台能做什么 |
| --- | --- |
| 一个标的过去怎么走 | 按代码、币种或公司名搜索。支持 1、5、15、30 分钟，1、4 小时，以及日、周、月线。公开行情源能提供的历史长度因标的和周期而异。 |
| 趋势从哪里起、在哪里反复 | 在 K 线上叠加分型、笔、线段、中枢和历史信号。笔中枢看局部重叠，线段中枢看更大一段走势，两层可以单独开关。 |
| 后面看哪些价位 | 结构足够清楚时，查看做多或做空方案的入场区间、触发条件、止损和两档止盈。方向待明时先看支撑和阻力。 |
| 这个方向有多少依据 | 对照缠论结构、MACD 动能、相对成交量和更大周期。多空百分比表示当前结构倾向；例如“多方 70%”描述的是评分，不能据此推算十次交易会赢七次。 |
| 当时能不能看出这个走势 | 用历史回放逐根推进 K 线，观察当时可见的结构。可导入自己的 OHLCV CSV，也可导出 K 线和分析结果复盘。 |
| 怎样一起看多个标的 | 加入自选，按当前周期开启监测。每轮最多检查前 12 个自选，两轮至少间隔 60 秒，只提示新变化。关闭工作台，监测随之停止。 |

加密货币连续交易，确认条件里的“K 线结束”指所选周期走完。股票按交易时段处理，4 小时线按交易所时段聚合。数据不足或行情过期时，界面会说明原因。工作台提供价格参考，交易由使用者自己决定和执行。

## 下载和使用

在 [Releases](https://github.com/nhovongoc0-max/trend-workbench/releases/latest) 选对应系统的 ZIP。两版都叫「趋势判断工作台」，默认中文，可切换英文。

| 系统 | 打开方式 |
| --- | --- |
| Windows 10/11 x64 | 完整解压到可写文件夹，双击「启动工作台.vbs」。工作台用 Microsoft Edge 独立窗口显示。 |
| macOS 15 或更高版本，Apple 芯片 | 解压，把「趋势判断工作台.app」拖到「应用程序」后双击。 |

**Mac 首次打开。** 本版本采用临时签名，尚未经 Apple 公证。如首次打开时系统提示无法验证开发者，请先确认应用来自本项目的 GitHub 发行页，然后到「系统设置」→「隐私与安全性」，在「趋势判断工作台」的提示旁点「仍要打开」，按系统提示确认。详情见 [Apple 的首次打开说明](https://support.apple.com/zh-cn/102445)。

两个压缩包都包含运行环境。行情通过网络获取，工作台在本机运行，无需 GPT 账号或交易账户。

**行情断开时**，工作台会按当前网络尝试其他现货来源，保持交易对和报价币一致。电脑可直连，也可沿用 Windows 或 macOS 的系统手动 HTTP/HTTPS 代理。刷新失败时，已经打开的图会保留同一标的、同一周期上次取得的 K 线，并暂停新信号。网络恢复后可点「刷新行情」。
